# Bundled fonts

Each folder holds one font as variable WOFF2 files — Latin and Latin Extended,
upright and (where the family has one) italic — and the licence it is
distributed under, `OFL.txt`. A downloaded site that uses a font carries that
font's folder with it, licence included, as the SIL Open Font License asks.

All were taken from the Fontsource packages, which repackage the Google Fonts
releases unchanged. `src/lib/fonts.ts` lists them for the builder.
